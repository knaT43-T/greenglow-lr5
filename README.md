## О проекте

GreenGlow — магазин натуральной косметики для осознанных покупателей. Лендинг знакомит с философией бренда, преимуществами натурального состава, каталогом из шести продуктов, отзывами и условиями доставки.

**Технологии:** HTML5, CSS3 (встроенные стили в одном файле), без JavaScript, без внешних шрифтов и библиотек. Используются системные шрифты и адаптивная вёрстка.

## Структура репозитория

```
.
├── index.html              # одностраничный лендинг
├── assets/img/             # локальные изображения товаров
│   ├── photo1.jpg
│   ├── photo2.jpg
│   └── photo3.jpg
├── docs/                   # материалы выполнения ЛР №5
├── report_screens/         # скриншоты для отчёта
├── REPORT_CONTENT.md       # готовый текст отчёта
├── SCREENSHOT_CHECKLIST.md # чек-лист скриншотов
├── VERIFICATION.md         # итоговая проверка требований
└── README.md
```

## Ветки проекта

- `main` — основная ветка с актуальной версией сайта;
- `feature/add-images` — добавление трёх локальных изображений в каталог (ветка слита с `main`);
- `fix/remove-emoji` — альтернативная ветка с заменой эмодзи на строгие текстовые маркеры (не слита с `main`).

## Запуск локально

Откройте файл `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000/`.
