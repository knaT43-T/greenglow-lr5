# Состояние сайта «до» и «после»

## До изменений (ветка `main`, первый коммит)

В первых трёх карточках каталога использовались текстовые заглушки:

```html
<div class="product-img">
  <span class="product-badge">Хит</span>
  <span class="product-placeholder">Увлажняющий крем с алоэ</span>
</div>
```

Заглушки выглядели как аккуратные градиентные блоки с названием товара, но не содержали изображений. Это исходное состояние сайта, восстановленного по ЛР №4.

Скриншоты:

- `report_screens/before_hero.png` — первый экран до изменений;
- `report_screens/before_full.png` — полная страница до изменений;
- `report_screens/before_mobile.png` — мобильная версия до изменений;
- `report_screens/before_mobile_full.png` — полная мобильная версия до изменений.

## После изменений (ветка `feature/add-images`)

В первых трёх карточках каталога заглушки заменены на локальные изображения:

```html
<div class="product-img">
  <span class="product-badge">Хит</span>
  <img src="assets/img/photo1.jpg" alt="Увлажняющий крем с алоэ" width="1200" height="900" loading="lazy" decoding="async">
</div>
```

Аналогично добавлены `photo2.jpg` и `photo3.jpg`. Изображения заполняют блок `.product-img` через `object-fit: cover`, бейджи остаются поверх.

Скриншоты:

- `report_screens/after_hero.png` — первый экран после изменений;
- `report_screens/after_full.png` — полная страница после изменений;
- `report_screens/after_catalog.png` — блок каталога после изменений;
- `report_screens/after_catalog_grid.png` — сетка каталога крупным планом;
- `report_screens/after_mobile.png` — мобильная версия после изменений;
- `report_screens/after_mobile_full.png` — полная мобильная версия после изменений.

## Что именно изменилось

| Параметр | До | После |
|---|---|---|
| Изображения в каталоге | 0 локальных изображений | 3 локальных изображения |
| Первая карточка | Текстовая заглушка | Фото/иллюстрация крема с алоэ |
| Вторая карточка | Текстовая заглушка | Фото/иллюстрация сыворотки с витамином C |
| Третья карточка | Текстовая заглушка | Фото/иллюстрация гидрофильного масла |
| CSS | Нет правил для `img` в карточках | Добавлено `.product-img img` с `object-fit: cover` |
| Сетка | 3×2 | 3×2, не сломана |
| Мобильная версия | 1 колонка, заглушки | 1 колонка, изображения корректны |

## Визуальная проверка

Скриншоты сняты в headless-браузере Microsoft Edge через Playwright при ширине 1440 px (десктоп) и 390 px (мобильный). На всех скриншотах изображения загружены, соотношение сторон сохранено, обрезка `object-fit: cover` не искажает продукты.
