# Промт агента

## Роль и среда

- **Агент:** OpenCode (режим автономного coding-агента), модель **DeepSeek V4.1 Flash Free**.
- **Среда:** Windows, терминал PowerShell, VS Code-совместимая рабочая папка, Git 2.55, GitHub CLI 2.102.
- **Доступ:** файловая система проекта, терминал, Git, GitHub CLI, генерация/подготовка изображений, headless-браузер Edge для скриншотов.

## Краткая версия исходного задания

> Полностью подготовить лабораторную работу №5 по дисциплине «Информатика» на тему «Организация репозитория в системе управления версиями Git» на базе сайта GreenGlow из ЛР №4. Нужно: восстановить сайт, создать публичный репозиторий на GitHub, не менее трёх ветвей, форк внешнего проекта, добавить минимум три локальных изображения в сайт с помощью агента, выполнить слияние ветки с `main`, опубликовать сайт через GitHub Pages, подготовить текст отчёта, чек-лист скриншотов и итоговую проверку. Работать автономно, логировать действия, не задавать лишних вопросов, при блокировке создать `BLOCKERS.md`.

## Полный промт для изменения сайта (добавление изображений)

Этот промт был сформулирован агентом на основе задания ЛР №5 и передан агенту для правки `index.html`:

> Ты работаешь с проектом GreenGlow в рабочей папке. В папке `assets/img` находятся три локальных изображения товаров: `photo1.jpg`, `photo2.jpg`, `photo3.jpg`.  
>   
> Задача:  
> 1. Открой `index.html` и найди блок каталога товаров.  
> 2. В первых трёх карточках замени текстовые заглушки `<div class="product-img">…</div>` на настоящие изображения из рабочей папки:  
>    - `assets/img/photo1.jpg` — увлажняющий крем с алоэ;  
>    - `assets/img/photo2.jpg` — сыворотка с витамином C;  
>    - `assets/img/photo3.jpg` — гидрофильное масло.  
> 3. Сохрани обёртку `.product-img`, добавь осмысленные `alt`-атрибуты и `loading="lazy"`.  
> 4. Добавь CSS: `.product-img img { width: 100%; height: 100%; object-fit: cover; display: block; }`.  
> 5. Не ломай адаптивную сетку каталога и не используй внешние ссылки на изображения.  
> 6. Изменения должны быть заметны визуально.  
> 7. Зафиксируй изменения в Git в ветке `feature/add-images`, создай коммит и отправь ветку на GitHub.  
> 8. Обнови `docs/agent_changes.md`: укажи промт, изменённые файлы, пути к изображениям, состояние «до» и «после».  
> 9. Сохрани diff в `docs/diff_add_images.diff`.

## Дополнительный промт для ветки `fix/remove-emoji`

> В ветке `fix/remove-emoji` убери декоративные эмодзи из логотипа и блока преимуществ. Вместо эмодзи используй строгие текстовые маркеры или простые CSS-элементы. Не подключай внешние иконки и шрифты. Сохрани эко-минималистичный стиль. Добавь `docs/branch_notes.txt` с описанием ветки, сделай коммит и отправь ветку на GitHub. Не сливай эту ветку с `main`.
