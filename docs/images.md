## Происхождение изображений

Изображения созданы агентом в рабочей папке проекта программно, с помощью Python 3.10 и библиотеки Pillow 12.1.1. Скрипт генерации: [`docs/tools/make_product_images.py`](tools/make_product_images.py).

Каждое изображение содержит:
- тёплый бежевый фон в палитре сайта (`#F9F6F0`, `#E6DED0`);
- продуктовый объект (банка крема, флакон сыворотки, флакон гидрофильного масла);
- ботанические элементы (листья, апельсин, капли воды);
- этикетку с надписью GreenGlow и названием продукта;
- мягкую тень и световые блики.

## Почему изображения созданы программно

При попытке использовать встроенный сервис генерации изображений агент получил ошибку:

```text
Access denied by security policy
```

Повторные попытки с другими параметрами и моделями дали тот же результат. Поэтому был выбран резервный путь, предусмотренный заданием: создать собственные изображения в рабочей папке программно. Это гарантирует:
- отсутствие внешних зависимостей и лицензионных ограничений;
- единый визуальный стиль всех трёх изображений;
- физическое наличие файлов в репозитории;
- использование относительных путей на сайте.

## Использование в HTML

```html
<img src="assets/img/photo1.jpg" alt="Увлажняющий крем с алоэ" width="1200" height="900" loading="lazy" decoding="async">
<img src="assets/img/photo2.jpg" alt="Сыворотка с витамином С" width="1200" height="900" loading="lazy" decoding="async">
<img src="assets/img/photo3.jpg" alt="Гидрофильное масло" width="1200" height="900" loading="lazy" decoding="async">
```

CSS:

```css
.product-img img {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}
```

## Проверка локальности

Все три файла находятся в папке `assets/img` рабочей папки проекта. В HTML нет ссылок вида `http://` или `https://` на изображения. При публикации через GitHub Pages файлы доступны по относительным путям `assets/img/photo*.jpg`.
