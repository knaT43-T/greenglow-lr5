# Материалы для отчёта

## Где лежат материалы

Все скриншоты находятся в папке `report_screens/` в корне репозитория. Текст отчёта — в `REPORT_CONTENT.md`. Чек-лист — в `SCREENSHOT_CHECKLIST.md`. Итоговая проверка — в `VERIFICATION.md`.

Скриншоты сняты в headless-браузере Microsoft Edge через Playwright:

- десктоп — viewport `1440 × 900`, deviceScaleFactor `1`;
- мобильный — viewport `390 × 844`, deviceScaleFactor `1`;
- полные страницы — `fullPage: true` (высота обрезана по последнему содержательному блоку).

## Чего не хватает и как добрать

Все обязательные публичные страницы сняты. Единственный необязательный скриншот — страница `Settings → Pages`, которая требует авторизации. Если преподаватель просит именно её:

1. войти в GitHub под `knaT43-T`;
2. открыть `https://github.com/knaT43-T/greenglow-lr5/settings/pages`;
3. снять скриншот с настройками `Deploy from a branch`, `main`, `/ (root)`;
4. сохранить как `report_screens/13_pages_settings_manual.png` и добавить в отчёт после рисунка 9.

Факт публикации уже подтверждён API, успешным run и скриншотами самого сайта, поэтому этот скриншот не является блокирующим.
