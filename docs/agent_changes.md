## Промт

Агенту был передан следующий промт (полная версия — в `docs/agent_prompt.md`):

> Ты работаешь с проектом GreenGlow в рабочей папке. В папке `assets/img` находятся три локальных изображения товаров: `photo1.jpg`, `photo2.jpg`, `photo3.jpg`.  
> Задача: открой `index.html` и найди блок каталога. В первых трёх карточках замени текстовые заглушки на изображения из рабочей папки: `photo1.jpg` — увлажняющий крем с алоэ, `photo2.jpg` — сыворотка с витамином C, `photo3.jpg` — гидрофильное масло. Сохрани обёртку `.product-img`, добавь осмысленные `alt`-атрибуты и `loading="lazy"`. Добавь CSS `.product-img img { width: 100%; height: 100%; object-fit: cover; display: block; }`. Не ломай адаптивную сетку и не используй внешние ссылки. Изменения должны быть заметны визуально. Зафиксируй изменения в ветке `feature/add-images`, сделай коммит и отправь ветку на GitHub. Обнови `docs/agent_changes.md` и сохрани diff в `docs/diff_add_images.diff`.

## Пути к изображениям

Все пути относительные, изображения физически находятся в рабочей папке проекта:

```text
assets/img/photo1.jpg  →  <img src="assets/img/photo1.jpg" alt="Увлажняющий крем с алоэ">
assets/img/photo2.jpg  →  <img src="assets/img/photo2.jpg" alt="Сыворотка с витамином С">
assets/img/photo3.jpg  →  <img src="assets/img/photo3.jpg" alt="Гидрофильное масло">
```

## Что изменилось визуально

**До:** в первых трёх карточках каталога отображались текстовые заглушки с названием товара на градиентном фоне. Карточки выглядели как макет без товарных изображений.

**После:** в первых трёх карточках отображаются локальные изображения продуктов:
1. стеклянная банка крема с алоэ на бежевом фоне;
2. янтарный флакон сыворотки с витамином C и апельсином;
3. флакон гидрофильного масла с дозатором и каплями воды.

Изображения заполняют всю площадь блока `.product-img` благодаря `object-fit: cover`, не ломают сетку 3×2 и корректно отображаются на мобильных устройствах. Бейджи «Хит» и «Новинка» остаются поверх изображений.

## Проверка

- Все три изображения возвращают `naturalWidth > 0` при загрузке страницы.
- В HTML ровно три локальных `<img>` с относительными путями `assets/img/...`.
- Внешних ссылок на изображения нет.
- Сетка каталога сохраняет 3 колонки на десктопе, 2 на планшете и 1 на мобильном.
- Изображения имеют `alt`, `width`, `height`, `loading="lazy"`, `decoding="async"`.
- `git diff main..feature/add-images -- index.html` сохранён в `docs/diff_add_images.diff`.

## Примечание о способе получения изображений

Сервис генерации изображений, доступный агенту, вернул ошибку `Access denied by security policy` для всех запросов. Поэтому агент создал три собственных продуктовых изображения программно с помощью Python и Pillow: градиентный фон, стеклянная банка, янтарный флакон, флакон с дозатором, ботанические элементы и подписи GreenGlow. Скрипт сохранён в `docs/tools/make_product_images.py`, чтобы результат можно было воспроизвести. Это соответствует требованию «собственные изображения из рабочей папки»: файлы созданы агентом, лежат в `assets/img` и используются на сайте через относительные пути.
