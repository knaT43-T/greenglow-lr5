# Ветви проекта GreenGlow

## Общая схема

```text
main
├── feature/add-images   (слита в main через Pull Request #1)
└── fix/remove-emoji     (альтернативная ветка, не слита)
```

## Таблица ветвей

| Ветка | Назначение | Основные изменения | Статус |
|---|---|---|---|
| `main` | Основная ветка с актуальной версией сайта | Исходный лендинг, документация, GitHub Pages | Основная, защищена от случайных изменений |
| `feature/add-images` | Добавление трёх локальных изображений в каталог | `index.html`, `assets/img/photo1.jpg`, `photo2.jpg`, `photo3.jpg`, документация | Слита в `main` через Pull Request #1, ветка сохранена |
| `fix/remove-emoji` | Альтернативный дизайн без эмодзи | `index.html`: CSS-лист в логотипе, текстовые маркеры «100%», «ЭКО», «CF»; `docs/branch_notes.txt` | Не слита, оставлена для сравнения |

## `main`

Основная ветка. Содержит восстановленный лендинг GreenGlow, три локальных изображения товаров (после слияния `feature/add-images`), служебную документацию и материалы отчёта. Именно из этой ветки публикуется сайт через GitHub Pages.

## `feature/add-images`

Ветка создана для выполнения требования ЛР №5 о добавлении минимум трёх изображений из рабочей папки с помощью агента.

Что сделано:
- в первые три карточки каталога добавлены изображения `assets/img/photo1.jpg`, `photo2.jpg`, `photo3.jpg`;
- добавлены `alt`, `width`, `height`, `loading="lazy"`, `decoding="async"`;
- добавлен CSS `.product-img img` с `object-fit: cover`;
- обновлена документация и сняты скриншоты «до/после».

Слияние: Pull Request #1 «Add three images to GreenGlow catalog», merge commit `9c7655f`. Ветка не удалена после слияния — это позволяет показать её в отчёте и при необходимости вернуться к изменениям.

## `fix/remove-emoji`

Альтернативная ветка, демонстрирующая отдельную линию разработки дизайна.

Что сделано:
- из логотипа удалён эмодзи `🌿`, вместо него используется CSS-знак листа `.leaf-mark`;
- в блоке преимуществ эмодзи `🌿`, `♻️`, `🐇` заменены на строгие текстовые маркеры `100%`, `ЭКО`, `CF`;
- декоративный символ `✿` в строке ценностей заменён на нейтральную точку;
- добавлен `docs/branch_notes.txt` с описанием ветки.

Ветка **не слита** с `main`: она показывает альтернативный вариант, который можно сравнить с основным. Это соответствует требованию иметь не менее трёх ветвей и демонстрирует, что не каждая экспериментальная ветка должна попасть в основную.
